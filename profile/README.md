### Wer wir sind

**planni** macht Seminarverwaltung so einfach, wie sie sein sollte. Wir bauen das Tool, das B2B‑Trainingsanbieter, B2C‑Seminaranbieter und Coaches täglich tatsächlich *gern* benutzen — kein Excel‑Chaos, keine 90er‑Software, keine zehn Tabs nebeneinander.

Die entspannte Zukunft für Seminar‑Anbieter beginnt hier. Heute.
